# yosugala schedule viewer

[yosugala 公式サイトの SCHEDULE](https://yosugala.fanpla.jp/live_information/schedule/list/) を毎日記録したアーカイブの閲覧ページ。
サイトから消えた予定や、内容の変更履歴も見返せる。

- 閲覧: https://torochai.github.io/yosugala-schedule-viewer/
- `index.html` と `data.js` は毎朝 06:00 JST ごろに自動更新される（非公開の取得リポジトリから push）
- このリポジトリは表示専用。直接編集しても次回の更新で上書きされる

情報の出典はすべて公式サイトです。
